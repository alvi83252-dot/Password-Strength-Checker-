Password Strength Checker

Type a password in the panel, or run the same check in a terminal with python password_checker.py. Strength is scored locally. The Dark Web radar uses Have I Been Pwned with k-anonymity.

The full password stays in your browser. For the breach check, only the first 5 characters of a SHA-1 hash are sent to Have I Been Pwned. Use sample passwords for screenshots. Do not type a password you actually use.

The five checks

  1. At least 8 characters. 12 or more is safer.
  2. An uppercase letter (A-Z).
  3. A lowercase letter (a-z).
  4. A number (0-9).
  5. A special character such as ! ? # or @.

A space is allowed in a passphrase, but a space does not count as the special character.

How the rating is chosen

Weak
Shorter than the minimum length, found on a short local list of common passwords, fewer checks than the Weak threshold, or found in Have I Been Pwned breach data.
Moderate
Enough checks to clear the Moderate threshold, long enough, and not a common or compromised password.
Strong
All required checks passed, and not found in Have I Been Pwned breach data.

A password can look complicated and still be Weak. Password1! meets every character check, but Have I Been Pwned will mark it COMPROMISED with a breach count.
