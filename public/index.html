Password Strength Checker

Type a password in the panel, or run the same check in a terminal with python password_checker.py. Either way, the password stays on this computer.

This page checks the password in your browser. It is not sent to a server, not saved, and not written to a log. Use the sample passwords for screenshots. Do not type a password you actually use.

The five checks

  1. At least 8 characters. 12 or more is safer.
  2. An uppercase letter (A-Z).
  3. A lowercase letter (a-z).
  4. A number (0-9).
  5. A special character such as ! ? # or @.

A space is allowed in a passphrase, but a space does not count as the special character.

How the rating is chosen

Weak
Shorter than 8 characters, found on a short list of commonly leaked passwords, or fewer than 3 checks passed.
Medium
3 or 4 checks passed, at least 8 characters, and not a common password.
Strong
All 5 checks passed, and not a common password.

A password can look complicated and still be Weak. Password1! meets every character check, but it is widely known, so this tool rates it Weak.
